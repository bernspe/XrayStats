# Xray Analysis Jupyter Notebooks for xray-annotator app

1. log into https://xray-annotator.renecol.org
2. Go to Account info
3. Copy your token
4. Open the Jupyter Notebooks below and paste your token where indicated

## About the scripts
### user_activity
 - number of measured images by the number of measurement-datasets per image
 - Cumulative Number of Annotations Over Time by User
 - Cumulative Number of Images Over Time
 - Cumulative Number of Annotated Images Over Time

### reconstructing_spline
 - test for individual spline reconstruction using python-based methods (from bspline_python.py library)
 - only individual test cases, not batch processing

### comparing_angles
 - first try to compare regional hand-drawn COBB and spline-based COBB from xray-annotator
 - first try to depict an individual measurement over time
 - not yet batch processing
 - not yet statistical evaluation
